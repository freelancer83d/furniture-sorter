# Bundled catalogue

Put your exported `category-structure.json` in this folder.

The app loads it automatically on first start (when the browser has no structure
saved yet), so a new user only needs to load a CSV. You can also re-apply it any
time from **Structure -> Reload catalogue shipped with the app**.

To update it: arrange the categories in the app, click
**Structure -> Export structure…**, and replace the file here.

If the file is missing, the app simply starts empty — nothing breaks.
